## 📌 О проекте

**SUDOKU BV** - это классическая игра Судоку, разработанная учениками 9Г класса в качестве итогового проекта по информатике. Игра включает в себя 4 размера поля, 30 уровней для каждого, систему звезд, 5 цветовых тем и музыкальный плеер.

**Ключевые слова:** судоку, игра на python, pygame, проект 9 класс, информатика, sudoku game, школьный проект, логическая игра, головоломка

---

## 🎯 Особенности

- **4 размера поля**: 3x3, 6x6, 9x9 и бонусный 12x12
- **30 уровней** для каждого размера (всего 120 уровней)
- **Система звёзд** за скорость прохождения
- **5 цветовых тем** (переключение в реальном времени)
- **Музыкальный плеер** с автоматическим плейлистом
- **Звуковые эффекты** победы/поражения
- **Автосохранение** прогресса
- **Режимы сложности**: Новичок / Опытный

---

## 🎮 Режимы игры

### 📚 Режим изучения
- Таймер отключен - играйте без спешки
- Автоматическая победа при решении
- 3 звезды за любой правильный ответ
- Идеально для новичков

### ⚡ Испытательный режим
- Классическая игра с таймером
- Звезды зависят от скорости
- Поражение при превышении времени

### 🏆 Турнирный режим
- Усложненный таймер (70% времени)
- Двойные звезды за победу
- Для настоящих чемпионов!

|----------|---------|

| Цифра | Клавиша |
|-------|---------|
